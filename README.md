# majiang-core

麻雀基本ライブラリ

手牌の操作、シャンテン数・和了点計算、局進行・卓情報の管理、思考ルーチンの雛形を含む基本クラス群を提供します。

ver.2.0.0 以降の[電脳麻将](https://github.com/kobalab/Majiang)は、その実装に本パッケージを使用しています。

## インストール
```sh
$ npm i @kobalab/majiang-core
```

## 使用法
```javascript
const Majiang = require('@kobalab/majiang-core');
```

## 提供機能
| クラス名            | 機能                                 |
|:--------------------|:-------------------------------------|
| ``Majiang.Shoupai`` | 手牌を表現するクラス                 |
| ``Majiang.Shan``    | 牌山を表現するクラス                 |
| ``Majiang.He``      | 捨て牌を表現するクラス               |
| ``Majiang.Util``    | シャンテン数計算、和了点計算ルーチン |
| ``Majiang.Game``    | 局進行を実現するクラス               |
| ``Majiang.Board``   | 卓情報を更新するクラス               |
| ``Majiang.Player``  | 対局者を実現する基底クラス           |

## 三人戦対応(ローカルフォーク拡張)

本フォークは upstream v1.4.1 をベースに、同一の `Game`/`Board`/`Shan`/`Util`
コードを人数 N(3 または 4)でパラメータ化したローカル専用フォークです。
GitHub へのフォーク・公開は行いません。`人数` を指定しない場合は従来の
四人戦既定値と対局挙動を維持します。

### 使い方

ローカル clone のルートから実行する場合:

```javascript
const Majiang = require('./');

const rule = Majiang.rule({
    '人数':         3,
    '場数':         1,                      // 東風戦 = 東1〜東3
    '赤牌':         { m: 0, p: 0, s: 0 },   // 三人戦で赤萬子は使用不可
    '役満パオあり': false,                  // 三人戦の役満パオは未対応
});

const game = new Majiang.Game(players, callback, rule);
game.kaiju();
```

### 三人戦ルール仕様

| 項目             | 三人戦                          | 四人戦(変更なし)               |
|:-----------------|:--------------------------------|:-------------------------------|
| 牌山             | 108枚(萬子は 1・9 のみ)          | 136枚                          |
| 配給原点         | 35,000                          | 25,000                         |
| 返し点           | 40,000                          | 30,000                         |
| ノーテン罰点     | 2,000(合計)                      | 3,000(合計)                    |
| 順位点           | +20.0 / 0.0 / −20.0             | +20.0/+10.0/−10.0/−20.0        |
| ツモ和了         | 実在する2名のみが支払う(ツモ損)  | 3名が支払う                    |
| 本場(ツモ)       | 支払者ごと +100(計+200)          | 支払者ごと +100(計+300)        |
| 本場(ロン)       | +300                            | +300                           |
| チー             | 不可                            | 可                             |
| 風牌             | 東・南・西(北はオヤなしの客風)   | 東・南・西・北                 |
| ドラ表示(萬子)   | m1⇔m9 で循環                    | n→n+1(9→1)                     |
| 四風連打/四家立直 | 適用なし                        | 適用あり                       |

- `Majiang.rule({'人数':3})` で三人戦用デフォルトを取得。`'人数'` は 3/4
  以外(`RangeError`)、三人戦での `'役満パオあり':true`・`'赤牌'.m>0`・
  `'順位点'` の要素数不一致・`'本場支払点'!==100` は例外となります。
- `Majiang.Shan.zhenbaopai(p, rule)` — 第2引数にルールを渡すと三人戦の
  m1⇔m9 ドラ変換を行います(従来は1引数)。
- `Majiang.Util.tingpai(shoupai, f_xiangting, rule)` — 第3引数にルールを
  渡すと三人戦で待ち候補から萬子2〜8を除きます(Game/Player 内部は
  自動的にルールを引き継ぎます)。
- `Majiang.Game.get_chi_mianzi(rule, ...)` は三人戦ルールでは常に
  `[]` を返します。
- `dev/game.js` のスクリプト対局も `rule['人数']` に追随します(従来どおり
  四人戦スクリプトはそのまま動作します)。
- 未対応: 三人戦の役満パオ、`'本場支払点'` が 100 以外の設定(いずれも
  例外で fail-fast)。
